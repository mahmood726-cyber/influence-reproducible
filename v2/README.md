# Paper 11 v2 reproduction layer (archive 1.1.0)

This separate layer records the allmeta influence page at release **v1.8.0** (tag `v1.8.0`, commit `1cb3f8409c7af75ed41f7e1811f9c502f900fc79`, DOI **10.5281/zenodo.23515177**), which contains pull request #170. The historical captures were taken at `f96772b`, an ancestor of v1.8.0, and keep their original file names; `../RELEASE_EQUIVALENCE.md` records the snapshot re-pin and the byte-identical re-execution on the v1.8.0 bytes. This archive is a local, unpublished build. DOI: **[ARCHIVE v1.1.0 DOI PENDING]**. The original archive v1.0.0 is identified by DOI 10.5281/zenodo.23415788. No source reference, original count, original app asset or original fitting helper has been changed.

From the archive root, run `Rscript validate.R`. Required: R **4.6.0**, metafor **5.2.1** (paper notation **5.2-1**), metadat **1.6.0** for v1, jsonlite **2.0.0**, digest **0.6.39**, and Python **3.13 or later** on PATH. Python uses only its standard library. Exact R/package mismatches fail closed. At most two R processes run: the parent plus one fitting/script worker. No downloads, installs, browser, network or historical fit cache are needed.

For v2 only, set `INFLUENCE_V2_ONLY=1` before the same command. This skips all v1 fits and is explicitly labelled in the log. V2 measured 274.9 seconds (4.6 minutes) on this node; allow 5–15 minutes on comparable hardware; the original default v1 run measured 475 minutes before this release's lower worker cap. The default runs both layers and exits nonzero on any failure. `outputs/v2/` contains fresh fits, full comparator ledgers, script logs/PDFs, and per-script results. Each run overwrites its current logs and freshly computes the fits; it does not resume from those files.

E2 and E1-S reuse the same archived leave1out references and are **not independent** of one another. E2's `tau2.del`/`QE.del` repeat the same deletion quantities as `loo.tau2`/`loo.Q` through a second metafor function; these are separate checks, not independent statistical evidence. Only E1-F/R and E3 execute new R calculations. R composes exclusion and comparison with `update(res, subset=...)` and comparison code; the app supplies an interactive UI for that workflow.

The fresh/stored-fit rule is **abs(stored − fresh) / max(1, abs(fresh)) ≤ 1e-12**, with exact k, configuration, set and exclusion identity. This is a stated tolerance, not a claim of 17-significant-digit identity. All eleven statistical fields per fit are checked; timing is not compared. The refit code retains the archive's starting-value rule and REML controls: `maxiter=10000`, `stepadj=1`, `threshold=1e-12*max(1,start_tau2)`. App-versus-reference tolerances remain the original comparators' 1e-6 for REML quantities and 1e-9 for Q/Qp, with exact counts/sets. Missing or incomplete coverage fails.

`python v2/tools/verify_release.py` checks release hashes, complete inventories and v1 byte preservation. `python v2/tools/test_safeguards.py` checks the entrypoint against the original, incomplete inventory rejection, bit-identity corruption and fresh-refit corruption without another long R run. `python v2/tools/plant_controls.py` temporarily corrupts each of the three requested inputs, calls the real v2-only `validate.R`, requires failure, and restores the exact original bytes in `finally`; run it when validation is idle. These integrity failures occur before fitting. The semantic safeguard tests and original comparator planted controls separately demonstrate numerical rejection.

The manager's `run_full.cmd` runs the complete default validator, writes `validate_full.log` and records UTC start/end timestamps and the exit code in `validate_full_run.json`. It explicitly clears the v2-only switch. It hard-codes no package library: set `R_LIBS_USER` (and `R_LIBS`) beforehand if the paper's R 4.6.0 / metafor 5.2.1 packages are not on R's own default path. `pins.R` gates the exact versions and fails closed, so a library without them cannot pass. The lane does not run this full command. The original v1 verifier remains archived unchanged and has a hard-coded metadata-1.0.0 assertion; use the new release verifier for 1.1.0 metadata and inventory. Root full-run logs/status are runtime outputs, excluded by the new release inventory helper in addition to v1's exclusions.
